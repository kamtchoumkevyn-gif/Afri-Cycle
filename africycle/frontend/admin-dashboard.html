Watch activity and review accounts that look suspicious.

The login secret (JWT_SECRET_KEY) is too short, so someone could forge logins. In Render, replace it with a random one of at least 32 characters, as the README's Security section explains.

Waiting for approval

Another admin must approve your admin account before you can use the admin tools. Ask them to open the admin page and tap Approve next to your name.

Protect your admin account

Install an authenticator app on your phone, such as Google Authenticator or Microsoft Authenticator. In the app, add an account with this setup key, then type the 6-digit code it shows. From then on, logging in as admin asks for the app's newest code.

Voice guide recordings

Phones have no voice for many of Africycle's languages. Record each sentence of the voice guide once in a language: everyone using Africycle in that language then hears your voice instead of nothing. Speak slowly and clearly, in a quiet place.
